# Описание проекта
## Приложение для анализа цен на сырьевые товары (нефть, газ, металлы). Демонстрирует работу с объектной моделью и конвейерной обработкой данных
# Запустить проект:
- Установить инструмент для запуска проекта(uv) командой 'make install'
- Собрать проект в пакеты командой 'make build'
- Запустить код самого проекта командой 'make project'
# Вывод:
## На экран выводится следующая информация:

## 1. Информация об источниках данных
Для каждого источника отображается:
- Имя источника
- Количество записей и тип источника
- Полный список всех записей в формате: `название: цена (Продавец: продавец)`
## 2. Результаты нормализации
Отображается количество нормализованных записей
## 3. Фильтрация по категориям
Для каждой категории (нефть, газ, золото, медь) выводится:
- Название категории
- Количество записей до фильтрации
- Количество найденных записей
- Отфильтрованные записи
## 4. Фильтрация по цене
Для заданного диапазона цен (1000-5000) выводится:
- Количество записей до фильтрации
- Количество найденных записей
- Отфильтрованные записи
## 5. Фильтрация по продавцу
Для заданного продавца (Лукойл) выводится:
- Количество записей до фильтрации
- Количество найденных записей
- Отфильтрованные записи
## 6. Общая статистика
Отображается:
- Общее количество записей
- Распределение записей по типам источников
- Статистика по каждой выполненной фильтрации
- Средняя цена по всем продуктам
## 7. Завершение работы
Сообщение об успешном завершении программы
