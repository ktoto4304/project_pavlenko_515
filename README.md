# Описание проекта
## Приложение для анализа цен на сырьевые товары (нефть, газ, металлы). Демонстрирует работу с объектной моделью и конвейерной обработкой данных
# Запустить проект:
- Установить инструмент для запуска проекта(uv) командой 'make install'
- Собрать проект в пакеты командой 'make build'
- Запустить код самого проекта командой 'make project'
# Вывод:
## На экран выводится следующая информация:
- Сообщение о начале работы программы
- Источники данных, их название, количество записей в каждом из них и сами записи
- Отчет по нормализации для каждого источника
- Фильтрация по категориям для каждого источника: Название категории, источника, отфильтрованные записи
- Фильтрация по цене для каждого источника: Название источника, отфильтрованные записи
- Общая статистика: средняя цена в каждом из источников
- Сообщение о завершении работы программы
